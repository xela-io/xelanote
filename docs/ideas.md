# Feature-Ideen für xelanote

Sammlung von geplanten Features und Verbesserungen für die Zukunft.

## Bereits umgesetzt (aus dieser Ideenliste)

- Graph Visualisierung / Relation Maps (Global Graph): `backend/internal/api/graph.go`, `frontend/src/routes/graph/+page.svelte`
- Version History: `backend/internal/api/versions.go`, `frontend/src/lib/components/VersionHistoryDialog.svelte`

## UI/UX Verbesserungen

### Mobile Ansicht
- Responsive Design für Smartphones und Tablets
- Touch-optimierte Bedienung
- Angepasste Navigation für kleine Bildschirme

### Dynamischeres UI
- Animationen und Übergänge
- Interaktive Elemente
- Verbesserte User Experience

### Farben & Symbole
- Icon-System für verschiedene Notiztypen
- Farbkodierung von Notizen/Ordnern
- Anpassbare Themes

### Design (Logo)
- Professionelles Logo-Design
- Branding-Konzept
- Corporate Identity

## Content-Features

### Zitation
- Automatische Quellenangaben
- Literaturverwaltung
- Zitierstile (APA, MLA, etc.)

### Whiteboard
- Visuelle Notizen und Skizzen
- Kollaboratives Brainstorming
- Freeform Canvas

### Bookmark
- Wichtige Notizen markieren
- Schnellzugriff auf häufig genutzte Inhalte
- Bookmark-Verwaltung

### Pin
- Notizen oben fixieren
- Priorisierung von Inhalten
- Schnellzugriff

### File Stats
- Anzahl Wörter, Zeichen
- Lesedauer
- Erstellungs-/Änderungsdatum
- Bearbeitungshistorie (Anzahl Änderungen)

## Erweiterte Funktionen

### Verschlüsselung
- End-to-End Verschlüsselung
- Verschlüsselte Notizen/Ordner
- Client-seitige Verschlüsselung
- Sichere Passwort-Verwaltung
